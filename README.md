# SKKU 3-2 — 시스템·임베디드 SW 학습과 구현 기록

송준혁(Junhyuk Song)의 **2026년 2학기 성균관대학교 6과목 학습·과제·캡스톤 아카이브**다. C/C++와 Python을 사용한 Linux 시스템 프로그래밍, xv6 운영체제 과제, RISC-V 명령어 처리, 알고리즘 구현, RoverAid를 연결해 볼 수 있다.

## 처음 읽는 사람과 자소서 작성 AI에게

1. **[경험·근거 지도](./경험-근거지도.md)**: 프로젝트·과제별 역할, 구현 내용, 기술적 선택, 결과와 파일 위치를 읽는다.
2. 아래 과목 README에서 관심 분야를 고른다.
3. **[PA·구현 전체 목차](./PA-학습목차.md)** → 해당 과제의 `study.md` → 실제 소스·제출 보고서 순서로 확인한다.
4. 학습 내용이 필요하면 주차별 `study.md`, 일정·제출 상태는 **[tasks.md](./tasks.md)**와 과목 `assignments.md`에서 확인한다.

각 경험의 목표·역할·구현·결과를 한눈에 보고, 관심 있는 프로젝트의 코드와 보고서로 바로 이동할 수 있도록 정리했다.
