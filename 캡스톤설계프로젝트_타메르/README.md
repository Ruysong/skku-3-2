## 바로 기억할 것

- Project-based, team-oriented course.
- 시험 없음.
- 팀 인원: Proposal Template 기준 3~4명, 4명 구성 권장.
- 첫 오프라인 수업에서 관심 프로젝트/아이디어를 공유하고 팀 매칭 예정.
- 실습비 지원/정산 자료는 `1주차/financial-support/`에 보관.
