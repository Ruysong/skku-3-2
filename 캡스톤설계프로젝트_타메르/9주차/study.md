## 수업 내용과 공부 정리

### 보고서에서 확인한 진행 기록

- 팀: 기구·하드웨어, 통신 런타임, 역기구학·상태 추정 담당으로 구분한다.
- 송준혁 담당은 보고서상 Python 노트북 서버와 C++ Raspberry Pi 클라이언트, 명령·telemetry 채널 분리, 길이 접두부 JSON, 유효성 검사, 연결 종료·3초 timeout 시 MockMotor 정지, 자동 재접속이다.
- 실물 Pi Wi-Fi 검증·영상 기록은 보고서의 완료 기록이다. 이번 저장소 동기화에서 직접 재실행한 결과는 아니다.
- 실제 모터·센서 연결은 보고서에서 미완료·후속 작업으로 구분한다. MockMotor 동작을 실제 로버 주행 완료로 바꾸지 않는다.
- 하드웨어 조립 및 IK/EKF 후속 작업, 실측 파라미터·부품 배송 의존성이 별도로 적혀 있다.
- 보고서는 11/6 영상 목표를 언급한다. 최신 공식 과제 공지와 대조하기 전, 확정 제출 마감이나 발표 날짜로 단정하지 않는다.

## 정리 상태

사용자 요청에 따른 **주차 폴더·기본 목차 세팅본**이다. 이번 작업에서는 강의자료 전체를 읽고 새 상세 교안을 작성하지 않았으므로 1만자 미만이다. 이후 상세 study 작성을 요청받으면 실제 PDF·영상 자료를 확인하고 저장소 프로토콜의 분량·눈검수 기준에 맞춰 확장한다. 파일 존재만으로 수강·실습·제출 완료를 표시하지 않는다.
