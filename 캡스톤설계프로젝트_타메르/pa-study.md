# 캡스톤 프로젝트 학습목차

이 과목은 PA 번호로 구분되는 개별 코드 과제가 아니라 팀 프로젝트 산출물로 관리한다.

| 산출물 | 확인된 내용 | 보관 |
| --- | --- | --- |
| RoverAid Proposal | 12페이지 제안서, 문제·구조·역할·평가 계획 | [제안서 PDF](./4주차/Team%20RoverAid_Capstone%20Design-Proposal_2026.pdf) |
| Proposal Presentation | 발표 자료 파일 | [발표 PPTX](./5주차/RoverAid_Proposal_Presentation.pptx) |
| 프로젝트 구조 학습 | 설계상의 데이터·명령 흐름과 구현 증거 구분 | [설계 교안](./4주차/project-study.md) |
| 중간발표 템플릿 | 13슬라이드 양식, 완성 발표자료와 구분 | [PPTX](./중간발표/CapstoneDesign-MidPresentation-Template2026.pptx) |
| Bi-Weekly Report | 양식과 작성본을 분리. 작성본에 본인 통신 런타임 구현·MockMotor 검증 기록 | [9주차 보고서 자료·진행 목차](./9주차/study.md) |

사용자가 제안서 제출과 발표 자료 완성을 확인했다. 새 보고서는 통신 런타임 구현·실물 Pi의 MockMotor 검증을 완료 기록으로 적고 있으며, [본인 코드 저장소](https://github.com/Ruysong/autonomous-rescue-rover)를 연결한다. 실제 코드는 별도 저장소에 있고 이번 작업에서 그 저장소를 재검증하지 않았다. 실물 모터·센서 연결과 로버 전체 주행 완료는 보고서에서도 후속 작업으로 구분한다.
