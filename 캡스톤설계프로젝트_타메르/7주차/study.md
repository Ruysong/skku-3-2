## 기록 구조

```text
교수님 / 팀 피드백
  -> 변경된 요구사항과 제작 범위
  -> 팀원별 담당 작업
  -> software / hardware 산출물
  -> 테스트 결과와 남은 문제
  -> 다음 회의 또는 발표에 사용할 자료
```

새 공지, 팀 회의 내용, 실제 구현·구매 결과가 들어오면 구분된 제목 아래 누적한다. 팀에서 결정하지 않은 기능·역할·구매를 임의로 확정하지 않는다. 7주차 원본 자료는 아직 이 폴더에 없다.

## 발표 일정 구분

자료의 중간 발표 계획은 9주차다. 학기 달력으로는 10/26~11/1 주간이며, 금요일 수업에 한다면 10/30이지만 **확정 발표일은 아니다**. 이번 주 금요일은 10/16이며, 별도 발표 지시가 확인되지 않았다. 캡스톤은 필기시험이 없는 팀 프로젝트 과목으로 다른 과목의 중간고사 일정과 분리한다.

## 정리 상태

주차별 기록을 시작하기 위한 세팅본이며, 새 강의·회의 원문이 없어 짧게 두었다. 실습비·부품 구매·팀 문서를 새 주차로 일괄 이동하지 않고 기존 원본을 유지한다.
