# 컴퓨터공학세미나 6주차 (2026-10-05~10-11)

## 주간 요건

이 과목은 매주 온라인 세미나 시청과 피드백 리포트 제출을 **둘 다** 충족해야 한다. 15주 중 최소 12주를 충족해야 Pass다.

- [ ] 6주차 영상·자료, 시청 가능 기간, 발표자를 확인한다.
- [ ] 영상을 시청하고 출결 상태를 확인한다.
- [ ] 교수님 템플릿 기준으로 이번 주 피드백 리포트를 작성·제출한다.
- [ ] 실제 마감과 제출 완료 화면을 확인한다.

이번 주 세미나 제목과 원본 자료는 아직 이 폴더에 없다. 이전 주의 자료나 보고서를 이번 주 것처럼 쓰지 않는다.
