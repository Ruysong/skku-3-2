## 바로 기억할 것

- 온라인 사전 녹화 세미나 수업입니다.
- Pass/Fail 평가이고 중간/기말 시험은 없습니다.
- 매주 피드백 리포트 제출이 필수입니다.
- 15주 중 최소 12주 이상 출석과 과제를 모두 충족해야 P를 받을 수 있습니다.

## 운영 메모

- 공지는 notices.md에 원문과 핵심 체크를 누적합니다.
- 매주 영상 시청/리포트 제출 여부는 assignments.md와 해당 주차 study.md에서 관리합니다.
- 세미나 자료가 올라오면 해당 주차 폴더에 보관하고, 리포트 초안도 같은 주차 study.md에 정리합니다.
