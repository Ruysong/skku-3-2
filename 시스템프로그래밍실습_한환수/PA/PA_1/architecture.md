# PA1 File Search - 구현 구조도

사용자가 작성한 구조도 원문. 복습할 때 `VMShare/pa_1`의 실제 제출본과 함께 확인한다.

```text
                     ┌───────────────────────────────┐
                     │         main.c                │
                     │       프로그램 시작           │
                     │                               │
                     │  argv 검사 → open() → fd      │
                     └──────────────┬────────────────┘
                                    │
                                    ▼
               ┌────────────────────────────────────┐
               │           QUERY 입력               │
               │                                    │
 stdin ────────►│ io.c : read_query()                │
               │                                    │
               │ input_buf[8192]                    │
               │       │                            │
               │       ▼                            │
               │ query[4097]에 검색어 하나 조립     │
               └────────────────┬───────────────────┘
                                │
                                ▼
                       ┌─────────────────┐
                       │    main.c       │
                       │                 │
                       │ PA1EXIT 검사    │
                       │                 │
                       │ YES → 종료      │
                       │ NO  → lseek()   │
                       └────────┬────────┘
                                │
                                ▼
               ┌────────────────────────────────────┐
               │        검색 종류 판별              │
               │                                    │
               │ 단어 하나      → Search 1          │
               │ 여러 단어      → Search 2          │
               │ "구절"         → Search 3          │
               │ word1*word2   → Search 4          │
               └────────────────┬───────────────────┘
                                │
                                ▼
┌────────────────────────────────────────────────────────┐
│                      search.c                          │
│                                                        │
│  검색 대상 파일                                        │
│        │                                               │
│        ▼                                               │
│  read(fd, buf, 65536)                                 │
│        │                                               │
│        ▼                                               │
│  buf[65536]                                            │
│        │                                               │
│        │ 문자 하나씩 검사                              │
│        ▼                                               │
│  io.c : line_append()                                  │
│        │                                               │
│        ▼                                               │
│  LineBuffer                                            │
│  ├── data       : 현재 줄                              │
│  ├── length     : 현재 길이                            │
│  └── capacity   : 확보된 공간                          │
│        │                                               │
│        │ '\n' 발견 → CR 제거 → 한 줄 완성              │
│        ▼                                               │
│  ┌─────────────────────────────────────────────────┐   │
│  │                검색 실행                        │   │
│  │                                                 │   │
│  │ Search 1 → search_line()                         │   │
│  │ Search 2 → search_multi_line()                   │   │
│  │ Search 3 → search_phrase_line()                  │   │
│  │ Search 4 → search_pattern_line()                 │   │
│  │                                                 │   │
│  │ 공통: word_equal() → lower_ascii()               │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                              │
│                         ▼                              │
│                검색 결과 생성                          │
│                         │                              │
│                         ▼                              │
│                output_buf[65536]                       │
│                         │                              │
│                   write_all()                          │
│                         │                              │
│                         ▼                              │
│                    stdout (1)                          │
│                                                        │
│  line_clear() → 다음 줄 처리                           │
│       │                                                │
│       └── EOF까지 반복                                 │
│               │                                        │
│               ▼                                        │
│     마지막 줄 처리 → 줄바꿈 출력                       │
│               │                                        │
│               ▼                                        │
│          line_free()                                   │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
                     ┌──────────────┐
                     │    main.c    │
                     │              │
                     │ 다음 query   │
                     │      │       │
                     │      └───────┼──► read_query()
                     │              │
                     │ 종료 시      │
                     │ close(fd)    │
                     └──────────────┘
```
