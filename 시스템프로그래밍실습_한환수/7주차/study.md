## PA2 연결

```text
수업의 process / signal / file I/O 내용
  -> Command-line Shell 과제
  -> 명령 해석과 child process 실행
  -> pipeline / redirection
  -> process group / signal 처리
  -> 구현·테스트·설계 보고서
```

이 구조는 PA2의 준비 방향이며 이번 주 수업의 확정 목차가 아니다.

- PA2 마감: 원본 p.5 기준 **11/1(일) 23:59**. 이번 주 마감이 아니다.
- 제출물: source code와 Makefile을 포함한 `STUDENTID_pa2.tar.zst`, 설계·구현 내용을 담은 PDF 보고서.
- 세부 제한과 기능은 PA2 원본을 우선하며, 주간 실습 조건과 섞지 않는다.
- 구현·제출 완료 여부는 미확인이다.
