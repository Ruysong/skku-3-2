# 운영체제 - 신동군 3주차 학습지도

## 상태

- 3주차 폴더와 학습 노트 준비 완료.
- 강의자료, 온라인 콘텐츠, 퀴즈 범위, xv6 과제 안내가 들어오면 원문 기준으로 반영한다.

## 이번 주 수집할 것

- OS 강의 PDF와 온라인 영상 목록/마감
- 매주 퀴즈의 일정, 범위, 응시 방식
- xv6 개인 과제의 단계, 제출처, 마감
- Process와 Limited Direct Execution 이후 이어지는 주제

## 학습 정리

강의 자료를 받은 뒤 핵심 구조도, 용어, 구현 흐름, 시험 대비 서술 포인트를 누적한다.
