# 시스템프로그램 — C·어셈블리·성능의 연결

C 프로그램의 정보 표현, 기계어 수준 실행, 메모리 구조와 성능을 공부한 과목이다. 데이터 표현·C/어셈블리·성능 분석 과제를 수행하고 이를 시스템 구현의 기초로 연결했다.

## 학습과 산출물

| 영역 | 다룬 내용 | 근거 |
|---|---|---|
| 정보 표현 | 비트 연산, 정수·부동소수점, 형변환 | [Chap.2 과제·설명](./Assignment/Assignment_1/study.md), [과제 목차](./pa-study.md) |
| Code Representation | C/어셈블리, 배열, 구조체·union, 스택 | [Assignment 02 범위](./assignments.md#assignment-02---code-representation), [제출물 폴더](./Assignment/Assignment_2/) |
| 성능 최적화 | CPE, loop unrolling, dependency, accumulator, branch, profiling·Amdahl | [10주차 자료](./10주차/), [11주차](./11주차/study.md), [12주차](./12주차/study.md) |
| 메모리 계층 | SRAM/DRAM·저장장치·지역성·캐시 연결 | [12주차 학습지도](./12주차/study.md)와 연결 교안 |

자소서에서는 [P1 경험 카드](../경험-근거지도.md#p1--c-코드가-기계에서-실행되는-원리)를 통해 다른 구현 과제의 근거 지식으로 연결한다. 교안·문제풀이·주차별 정리를 함께 읽을 수 있다.
