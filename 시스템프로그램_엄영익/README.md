## 바로 기억할 것

- 수업은 flipped-class 방식입니다.
- 온라인 강의는 매주 약 150분이며 iCampus에서 출결이 자동 확인됩니다.
- 오프라인 수업은 목요일 15:00-16:15, 강의실 26310입니다.
- 퀴즈는 학기 중 약 10회, 보통 목요일 15:05-15:15 예정입니다.
- 과제 수행을 위한 AI 엔진 사용은 금지되어 있습니다.
