## 바로 기억할 것

- 평가 비율은 Midterm 30%, Final 40%, Programming Assignments 30%입니다.
- 결석은 4회까지 penalty 없이 가능하지만, 4회 초과 시 10% 감점, 전체 1/4 초과 결석 시 F입니다.
- 녹화강의는 iCampus에 올라오지만 출석 대체가 아닙니다.
- PA는 RISC-V simulator를 단계적으로 만드는 방향이며 총 3개 예정입니다.
- 마지막 PA는 1만라인 프로젝트 과제와 연결된다고 안내되었습니다.
