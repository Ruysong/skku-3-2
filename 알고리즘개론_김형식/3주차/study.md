# 알고리즘개론 - 김형식 3주차 학습지도

## 상태

- 3주차 폴더와 학습 노트 준비 완료.
- 강의 PDF, iCampus 영상 제목/마감, 퀴즈 문제 형식, 공지를 받은 뒤 원문 기준으로 누적한다.

## 이번 주 수집할 것

- 교수님 강의자료와 iCampus 콘텐츠 목록
- 퀴즈의 문제 수, 시간 제한, 제출 방식, 정확한 범위
- PA 1 Merge Sort 제출처와 제출 상태
- 영어 서술형 대비: assumptions, pseudocode 해석, correctness, complexity 요구 여부

## 학습 정리

새 원본 자료를 기준으로 파일별 목차, 핵심 구조도, 개념 설명, 예상 서술형 답안 구조를 이곳에 추가한다.
