원문 메모:

```text
weak induction은 (k-1)th step이 true라고 가정하고, kth step이 true임을 보이는 것입니다.
strong induction은 m < k step들이 true라고 가정하고, kth step이 true임을 보이는 것입니다.

위 노트의 예제를 참고하면 좋을 것 같습니다.
```
